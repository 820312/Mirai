实习项目

参与面向跨境电商从业者的 Agent 工作流自动化平台「魔方AI」的 V0.4→V0.6 迭代。 V0.4 负责面向 FDE 实施团队的需求采集产品 0-1；V0.5 与 V0.6 转向平台内的选品能力建设， 完成选品页原型搭建、TikTok Shop 等相关选品节点 PRD 与多平台数据接入方案。

需求采集效率提升 10 倍 选品页原型搭建 竞品调研 10 份+ FastMoss / 1688 / 亚马逊 / TikTok 接入

核心工作

  • V0.4 · FDE 需求采集产品 0-1：通过抖音、微信社群触达跨境卖家并开展一对一访谈，梳理广告投流、选品上架、Listing 优化、达人建联等高频场景；独立完成 Figma 高保真原型与 PRD，融合「AI 电话 + 在线对话 + 自助表单」3 种采集通道，让卖家 3 分钟说清需求并自动生成结构化需求表。
  • V0.5 · 选品页原型搭建与整合：负责选品页 0-1 设计，使用 Figma 人工绘制并借助 Codex 输出可交互原型；作为选品页面负责人，与其他模块负责人合并完成魔方 AI 整体原型。

单据处理效率提升 67%（1h→20min） 线路方案单次节省 3h+ 361 位老师秒级语义匹配 Coze + 阿里云数据库

核心工作

  • 需求调研 · 能力定义：深入财务、运营、教务三条业务线，梳理报销、线路、师资的高频人工场景，输出需求分析文档，明确 3 个 Agent 的能力边界与输入输出规范。

  • 师资管理 Agent：从 361 位老师的结构化师资库语义检索，输出主推 1 位 + 备选 3 位的完整信息表与匹配理由，师资调度从人工翻表变为秒级匹配。
  • 交付 · 培训 · 迭代：独立完成 3 个 Agent 的搭建、测试、上线全流程，撰写操作手册并培训业务团队；基于反馈推动 5 项功能优化。
